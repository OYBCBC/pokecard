# 宝可梦 · 徽章之路（Pokémon Badge Run）

> **Balatro 式卡牌构筑肉鸽 × 宝可梦素材** —— 免费浏览器小游戏（非官方粉丝作品）
>
> 打出扑克式手牌组合击败 8 大道馆与冠军：80 张宝可梦卡（8 属性 × 10 力量档）、27 种携带道具、
> 7 种消耗品（含删卡/加卡/复制卡/闪光制作）、道馆主剧情对话、闪光宝可梦与图鉴、
> 每周挑战种子 + 本地排行榜、手机竖屏适配、存档续玩。

**在线试玩**：[https://oybcbc.github.io/pokecard/](https://oybcbc.github.io/pokecard/)
（GitHub Pages 部署；纯静态环境下云端周榜自动回退为本机榜，PWA 离线可用。
云端榜单接口需要 `tools/serve.py` 部署，见下文）

## 运行

```bash
cd gym-run
python3 tools/serve.py 8347     # 静态文件 + 云端周榜 API（/api/score, /api/board）
# 打开 http://127.0.0.1:8347
```

无需安装任何依赖，纯静态文件（ES 模块需 HTTP 服务，不能直接双击 file:// 打开）。
`tools/serve.py` 会发送 `Cache-Control: no-store`，改代码后刷新即生效，推荐使用。
**云端周榜依赖这个 Python 服务器**（成绩存在 `scores.json`）；用 `python3 -m http.server` 或
其他纯静态托管时，周榜自动回退为本机记录。

## 玩法

- **牌组**：80 张卡 = 8 种属性（火/水/草/电/超能/格斗/毒/一般）× 力量 1~10，每张都是一只宝可梦。
- **手牌判定**（扑克规则移植）：一对/两对/三条/顺子/同花/葫芦/四条/同花顺/高牌 +
  特殊 **五连击**（5 张同力量值——因为每档力量在 8 个属性里各有一只，这是可能凑出的！）。
- **计分**：`（手牌基础攻击 + 卡牌攻击 + 道具加成）×（基础倍率 + 道具倍率）`，就是打出的伤害。
- **流程**：每场战斗 4 手牌机会、3 次弃牌，把对手血条打空即胜；胜利领奖金 + 存款利息（每 $5 利息 $1，上限 $6），
  在友好商店买**携带道具**（最多 5 个，小丑牌位）和**消耗品**。
- **消耗品**：蛋白质/锌补剂强化卡牌，升级数据提升手牌等级，
  **离洞绳**放生删卡（牌组至少留 20 张）、**精灵球**随机捕获新卡（5% 闪光）、
  **重复球**复制一张卡、**珍贵球**把一张卡变成闪光（+80 攻击，换闪光立绘）。
- **道馆主规则**：小刚削弱火属性、小霞减弃牌、马志士减手牌上限、莉佳催眠手牌、阿橘减手数、
  娜姿随机封锁属性、夏伯削弱同花、板木倍率封顶 12 —— 馆主战前有剧情对话、战后有专属台词，
  战斗界面使用道馆主题色，每个馆主逼你调整构筑思路。
- **闪光与图鉴**：闪光卡使用专属闪光立绘与金边；顶栏图鉴跨局累积记录遇见过的宝可梦（剪影 → 点亮），
  闪光遇见单独点亮 ✨ 角标。
- **每周挑战**：标题页一键进入本周固定种子挑战（所有人同一局），**每周轮换七种变体规则**——
  标准周 / 精英周（敌人血量 +25%）/ 疾风周（手数 -1）/ 拮据周（奖励减半）/ 精简周（牌组只剩 60 张）/
  双属性周（牌组只剩随机两种属性 20 张）/ 决斗周（每场仅 2 手牌，血量 -40%），
  按周号确定性轮换。结算自动提交**云端共享榜**（令牌去重 + IP 限流防刷，不可用时回退本机 Top 10），
  积分 = 胜场×1000 + 最大单手伤害 + 通关 5000。
- **设置**：⚙ 里可调音效/音乐音量、开关程序生成的场景化 8-bit 背景音乐（标题/战斗/商店不同曲风，
  WebAudio 实时合成，无音频文件）、设置周榜显示的训练师名。
- **分享**：结算页可一键生成战绩 PNG（徽章进度 + 统计 + 队伍立绘）保存分享。
- **种子与挑战码**：标题页可输入种子复现同一局；结算页生成 `GYM1.xxxx` 挑战码，
  朋友粘贴即可玩到**同一副牌的同一局**（含变体规则）；支持导出完整战报 JSON。
- **自定义挑战房**：任选 7 种变体 + 自定种子开局，适合自制关卡发给朋友。
- **双人热座**：P1/P2 轮流出战，各自养各自的构筑（道具/金钱/手牌等级独立），
  共享同一副牌组与商店；谁先输掉自己的战斗就判负，通关则夺冠。
  顶栏显示当前出战方，战报带 P1/P2 标签。

## 开发

```bash
# 判牌单元测试（15 例）
node tools/test-eval.mjs

# 引擎扩展功能测试（36 例：牌组操作/闪光/图鉴/周榜/变体/防刷/存档）
node tools/test-engine.mjs

# 数值平衡模拟（贪心机器人 × 40 局，输出各关到达率与通关率）
node tools/sim.mjs
```

当前平衡基线：不会弃牌检索、只买道具的贪心机器人约在第 6~7 个道馆倒下（下界）；
会检索、会升级手牌的真人有明显的通关空间。数值都集中在 `js/data.js` 的 `RULES`/`HANDS`/`ITEMS`，可自行调参。

### 设计要点

- **数据与表现分离**：引擎状态全部是可 JSON 序列化的纯数据（存档 = 直接序列化），
  道具效果是数据表里的钩子函数——未来整体替换素材包（"换皮"）只需换 data/assets。
- **计分动画**：`scoreHand()` 返回事件流（base → 逐卡 → 道具 → 规则 → 总计），UI 按事件流播放，
  引擎状态一步到位，动画不参与逻辑。
- **调试钩子**：URL 带 `?debug` 时暴露 `window.__gymrun.run`（实时局面）与 `window.__gymrun.sfx`，
  正常访问不暴露，防止用控制台作弊后污染云端周榜。

## 构筑流派指南

> 借鉴宝可梦 PVP 的经典流派思路，游戏里目前成型了这些玩法路线（道具组合才是灵魂）：

**速攻流（Hyper Offense）— 数值爆发**
- 核心：讲究围巾（每手+2倍率且每胜+2）+ 圣灰（每手+25攻击且每胜+25）双滚雪球，配生命宝珠 ×1.25。
- 打法：什么牌型都打，纯数值碾压。上手最快，怕板木的倍率封顶（12）。

**单属性流（Monotype）— 天花板稳定**
- 核心：任一属性道具（木炭/神秘水滴/黑带…）+ 聚焦镜（同花+4倍率）+ 重复球复制该属性高力量卡。
- 打法：20 张同属性后同花几乎每手都有；夏伯（同花-3）是天敌。
- 变体：**天气流**——单属性 + 对应天气岩石（火队配大晴天 ×1.5；水/电队配下雨；格斗/一般队配沙暴；超能/毒队配冰雹），一个属性乘两个区。

**五连击流（Mega）— 极限上限**
- 核心：重复球把力量 10 的卡复制到 4~5 张 + 达人带（四条/五连击 ×1.5）+ 讲究头带（5张卡 ×1.4）。
- 打法：牌组薄下来后每手都是五条（120×12 基础），后期单手上万。成型最慢，成型后最猛。

**顺子流（Combo）— 灵活中坚**
- 核心：讲究眼镜 + 龙之牙（顺子合计 +60 攻 +3 倍率），配离洞绳删掉中间力量段让顺子更好凑。
- 打法：牌组保留连续力量段（如 4-8），灵活应对各种馆主规则。

**剧毒受队（Toxic Stall）— 消磨致死**
- 核心：剧毒宝珠（每打出一张毒卡叠 1 层中毒，每手结算 -20×层数）+ 气势披带（手数用尽追加 1 手）。
- 打法：不需要大牌，每手塞 2-3 张毒卡慢慢叠，第 4-5 手毒伤滚到每手几百；披带兜底拖后期。
  最"受队"的玩法——血条是被毒磨空的。

**经济流（Rich）— 曲线救国**
- 核心：剩饭（每胜+$2）+ 护身金币（+$3）+ 幸运蛋（商店打折）+ 满利息存款。
- 打法：前期故意存钱吃 $6/场利息，中期疯狂买高价道具转型以上任意流派。成型最快但战力滞后。

**高牌流（Meme）— 一击入魂**
- 核心：广角镜（高牌 ×2）+ 大葱（力量5 +8倍率）+ 重复球复制力量 5。
- 打法：单张 5 硬刚，数字不大但节目效果拉满。
